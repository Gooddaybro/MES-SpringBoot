# 伺服电机控制器教学主数据

日期：2026-10-27。此项独立于 R003 模型适配器，不是工厂工艺规程、生产 BOM 或已审核的技术参数。

## 已核对的字段与约束

学习库 `127.0.0.1:3308/mes_study` 的四表均为 InnoDB，只有 ID 主键，没有物料/路线/工序编码唯一约束或外键。`sp_materile.materiel` 是物料编码，`flow_id` 关联 `sp_flow.id`，正常状态 `is_deleted='0'`；`mat_type`、审计日期和用户名必填。字典实际值：原材料 `material`、半成品 `PG`、成品 `FG`、单位 `PCS`。

`sp_flow_oper_relation` 存当前/前道/下道工序 ID 和编码、`sort_num`；首末类型分别 `firstOper`/`lastOper`。本次无永久表结构修改，不填 BOM 子项或库存数量。

## 可审阅与重复执行的 SQL

文件：`scripts/sql/servo_controller_sample.sql`。默认不写入，只有同一会话显式设置 `@mes_servo_sample_confirm='LOCAL_LEARNING_ONLY'` 且当前数据库名为 `mes_study`、服务器端口为 3308 才能执行。连接必须由操作者确认是本机学习库，不能用于生产连接。

脚本使用连接内临时表准备数据，事务内先检查全部命名空间冲突；已有 ID/编码、描述、类型、路线、工序顺序或前后关联与样例不一致时，整组返回 `NO_CHANGE`。已有一致记录不更新，缺失记录才插入，不重写审计时间。无唯一业务编码约束，因此应在没有业务维护写入的学习环境执行；不声称能抗并发主数据维护。

PowerShell 批处理示例（私有客户端配置包含本地账号，勿提交）：

```powershell
$seed = Get-Content .\scripts\sql\servo_controller_sample.sql -Raw
$approved = "SET @mes_servo_sample_confirm='LOCAL_LEARNING_ONLY';`n" + $seed
$approved | & 'D:\Program Files\mysql-8.0.46-winx64\bin\mysql.exe' `
  --defaults-extra-file=.local/mysql-root.ini --host=127.0.0.1 --port=3308 `
  --database=mes_study --default-character-set=utf8mb4 --batch
if ($LASTEXITCODE -ne 0) { throw '种子SQL失败，请检查错误；不要使用 --force 继续执行。' }
```

需具备临时表和四张业务表 SELECT/INSERT 权限。此示例不要求扩展应用运行账号权限。出现错误时应让批处理退出，关闭连接会回滚未提交的事务；不要逐条跳过错误继续操作。
