# MES R003 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在现有 Java MES 中加入规则优先的受控模型识别、安全降级和可复现评测，独立准备伺服控制器样例主数据。

**Architecture:** 保留鉴权和只读工具。RestTemplate 客户端只识别两种意图；Java 对模型输出和原话候选双重校验后执行现有业务服务。

**Tech Stack:** JDK 8、Maven 3.6.3、Spring Boot 2.1.7、Jackson 2.9、JUnit 4、JDK HttpServer、Node 内置测试、MySQL 8 本地学习库。

---
