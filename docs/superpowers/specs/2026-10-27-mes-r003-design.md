# R003：受控模型意图识别

本轮在 `agent` 分支继续 R002；起点 `781ed2d`，工作区干净且与 `origin/agent` 一致。保持 Java 8、Boot 2.1.7、Shiro 和数据库只读工具，不引入 Python 或多步 Agent。

## 调用边界

`Shiro → Controller 登录/专用权限 → 原文长度 → 确定性规则 → 未解决时 LlmIntentClient → Java 原文候选校验 → MaterialRoutingService → 响应`。

规则可确定的单编码工艺查询直接查库；写入/SQL/提示注入、已知不支持业务、格式错误、多编码、缺少编码均可由 Java 拒绝或要求补充。仅含单个完整候选、意图未解决的问句交模型。中文汉字、空白和显式标点是分隔符；ASCII 字母数字与 `._/-` 保留在完整 token 中，非法符号不得剥离成合法前缀。模型编码必须与唯一候选区分大小写、逐字相同；不做大小写、全角、斜线、短横线或空格归一化。

## 适配器

`agent/LlmProperties` 从服务端环境读取 `MES_LLM_BASE_URL/MODEL/API_KEY`，超时默认连接 3000 ms、读取 15000 ms。base URL 是兼容服务的 API 根路径（如 `https://api.openai.com/v1`）；去尾斜线再追加 `/chat/completions`，已含该后缀则不重复。拒绝 user-info/query/fragment，禁止跟随重定向，HTTPS 用于远程服务，HTTP 仅供回环替身。缺配置不阻止启动或规则查询。

`agent/LlmIntentClient` 使用 RestTemplate/Jackson，单次非流式 Chat Completions，仅发送 system 意图指令及本次 user 原文。无历史记录、数据库返回、cookies、SQL 或工具定义。API Key 仅在服务端 Authorization 头。限定响应体与 content 大小，严格 JSON、必需字段/类型、意图白名单、编码格式；拒绝多余字段、重复字段及尾随 JSON。失败转稳定原因码，不记录响应原文或异常消息。

`LlmIntentResult` 是不可变识别结果（intent、materialCode、clarificationNeeded、attempted、failureReason）。客户端只校验输出契约；服务再次校验唯一原文候选，未通过不得调用工具。

质量审查落实：英文不全局忽略常用词，避免把 GO/IT/MAKE 等合法编码隐藏；仅完整英文问句语法可隔离原文编码区域，区域内所有 token 均保留。不完整的 routing for 不将介词当编码；多个或不明确 token 保守澄清。英文 route 关键词不能在编码内部触发规则。

## 响应与隐私

保留旧 status/mode/answer/material/routing/steps/source/traceId/elapsedMs。增加 RULE/MODEL/RULE_FALLBACK、modelAttempted、本次校验通过的 modelConnected、fallbackReason。成功识别后即使数据库失败，也保留识别来源。Controller 不再覆盖 modelConnected。匿名/无权限/结构化 GET 不调用模型。

前端逐次展示识别来源与降级原因，说明未解决问题可能发送给配置的模型；问题本身可能敏感，数据库事实不发送。前端等待时间覆盖模型与数据库分层超时。日志仅保留请求编号、状态、识别来源、失败码、耗时。

## 验收及范围

先补失败测试再实现；本地 HttpServer 覆盖有效响应、鉴权/限流/服务端错误、网络超时、非法/空/过长 JSON、未知意图、缺失字段及原文不一致。Controller 测试未授权无模型/工具调用；真实本地库 IT 保持只读。

30 条以内 JSONL 测试样例分别运行保留的 R002 规则与 R003 规则侧评测，统计语义准确率、编码准确率、错误工具调用、澄清率、模型请求比例、耗时。无真实凭据不发布混合真实准确率。伺服控制器样例主数据独立 SQL/说明，独立 ID/编码、事务、冲突拒绝、幂等；不改表结构、不覆盖现有数据。未来 preview_work_report 只记录 Java 预览/确认/事务/幂等设计，本轮无报工写入。

接口依据：[OpenAI 官方 Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。第三方兼容服务的参数支持仍需各自实测。
